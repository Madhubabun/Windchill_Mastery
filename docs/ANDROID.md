# Android app

## Installing the APK

1. Copy `windchill-mastery-<version>.apk` to the phone (or download it there).
2. Open it. Android asks to allow installs from that source (Files, Chrome, Drive...) the first
   time; allow it, then tap **Install**.
3. Open **Windchill Mastery**. Everything is inside the app, so it works in flight mode.

Requires Android 7.0 or newer. To get the daily reminder, turn it on in **Me → Settings** and
allow notifications when asked.

Installing a newer APK over an older one keeps your progress, **as long as both were signed with
the same key** (see below). Uninstalling the app deletes progress; use **Me → Settings → Export**
first if you need to keep it.

## How it works

`apps/android` is a small Java app with no Gradle project:

| File | Role |
| --- | --- |
| `MainActivity.java` | Full-screen WebView; serves `assets/www` at `https://app.windchillmastery.local`, maps `/path/` → `path/index.html`, sends other links to the browser, handles Back and file import |
| `Bridge.java` | `window.WindchillApp`: reminders, notification permission, print (Android print service, includes Save as PDF), share, open external links, app version |
| `Reminders.java`, `ReminderReceiver.java`, `BootReceiver.java` | Daily reminder alarm, notification channel, re-arming after reboot |
| `res/` | Launcher and notification icons (generated by `npm run icons`), theme, strings |
| `build.sh` | Builds the APK |

The site's service worker is not used in the app; the files are already on the device.

## Building

```bash
npm run build:web       # produces apps/web/out
npm run build:android   # produces apps/android/build/windchill-mastery-<version>.apk
```

`build.sh` uses plain SDK command-line tools: `aapt`, `javac`, `dx`/`d8`, `zipalign`,
`apksigner`, `keytool`, compiling against the API 23 `android.jar` (newer APIs are reached with
version checks). On Ubuntu/Debian:

```bash
sudo apt install android-sdk android-sdk-platform-23 openjdk-17-jdk-headless
```

With a full Android SDK instead, set `ANDROID_SDK` (and `ANDROID_JAR` to any
`platforms/android-XX/android.jar`) and make sure `aapt`, `zipalign` and `apksigner` from
`build-tools` are on `PATH`.

The version name and code come from the root `package.json` `version` (1.2.3 → code 10203). Bump
it before each release so Android accepts the update.

### Signing key

The APK is signed with `~/.android/windchill-mastery.jks`, created on the first build. Override
with `KEYSTORE`, `KEY_ALIAS`, `KEY_PASS`. **Keep this file**: an update signed with a different
key cannot be installed over the existing app (you'd have to uninstall and lose local progress).
Never commit it. For a Play Store release, generate a proper upload key and keep it in a secret
store.

### Publishing to Google Play later

Play requires an Android App Bundle (AAB) built with a current target SDK. The simplest route is
to create a standard Android Studio project with the same `MainActivity`/`Bridge`/receivers, put
the built site in `src/main/assets/www`, and build an AAB there. No web code changes are needed.
